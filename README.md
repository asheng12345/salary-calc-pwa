# 排班薪资计算器 · iPhone 可用版（PWA）

> 原项目为 PHP + MySQL 服务端架构（`install.php.zip` 根目录）。
> 本版本将核心功能**完全迁移到前端**，封装成一个可安装到 iPhone 主屏的 **PWA（渐进式 Web 应用）**，
> 无需服务器、无需数据库、无需 Mac / Xcode / App Store。

---

## 1. 架构概览

| 项 | 说明 |
|----|------|
| 形态 | 纯前端单页应用（SPA），零后端 |
| 技术栈 | 原生 HTML + CSS + JS，无框架、无构建步骤 |
| 存储 | 浏览器 `localStorage`（按用户名隔离） |
| 安装方式 | iPhone Safari「分享 → 添加到主屏幕」 |
| 离线 | Service Worker 缓存，断网可用 |
| 数据归属 | 仅存于本机浏览器，不上传任何服务器 |

## 2. 与原始 PHP 版的对应关系

| 原 PHP 版 | 本 PWA 版 |
|-----------|-----------|
| `users` 表 | 本地用户档案列表 |
| `salary_config`（cfg 参数） | 参数设置表单 |
| `salary_config`（salary 组成） | 自定义工资项（增/减） |
| `shifts` 表 | 月历排班（日/夜/休） |
| `holidays` 表 | 月历/列表节假日 |
| `api.php` 计算 | 前端 `app.js` 实时试算 |

> 原版 `debug` 等后端接口、多用户无鉴权等设计在本版中不再需要（数据本机私有）。

## 3. 薪资计算规则（默认模型）

设 **日工资 = 月基本工资 ÷ 月计薪天数**（默认 21.75）。

选定月份后：

| 工资组成 | 计算方式 |
|----------|----------|
| 基本工资（出勤） | 日工资 ×（白班天数 + 夜班天数） |
| 白班补贴 | 白班天数 × 白班补贴/天 |
| 夜班补贴 | 夜班天数 × 夜班补贴/天 |
| 法定节假日（上班） | 日工资 × 节假日倍率 × 上班天数 |
| 法定节假日（带薪假） | 日工资 × 休息天数（可在参数中关闭） |
| 自定义项 | 用户自行增删的「加项 / 减项」（如全勤奖、餐补、扣款） |
| **实发合计** | 以上各项求和 |

所有参数均可在「参数设置」中修改，计算实时可见、结果透明。

```

├── styles.css            # 样式（移动端优先）

└── README.md             # 本文档
```

## 5. iPhone 安装步骤（个人自用）

1. 将 `salary-app/` 整个目录部署到任意**静态托管**（HTTPS）：
   - GitHub Pages（免费，推荐）
   - Vercel / Netlify（免费）
   - 或任意支持 HTTPS 的网页空间
   - 本地自测：用 `python -m http.server` 起服务，但「添加到主屏幕」需 HTTPS 或 localhost 才生效。
2. 在 iPhone 上用 **Safari** 打开该网址。
3. 点底部「分享」按钮 → **添加到主屏幕** → 命名（默认「薪资计算器」）→ 添加。
4. 主屏出现图标，点开即全屏运行，可离线使用。

> 提示：iOS 16.4+ 对「添加到主屏幕」的 PWA 支持最完整；更早版本也能添加，但部分 PWA 特性（如 manifest 图标）可能用网页截图作图标。

## 6. 数据说明

- 数据保存在 Safari 的 `localStorage`，**清除 Safari 网站数据会丢失**。
- 建议定期「导出」或在界面复制数据备份（后续可扩展）。
- 多用户档案相互独立，切换即切换整套排班/参数。
